# 收款二维码放这里

把你的收款码图片放进本目录，Web「支持」页会自动显示，无需改代码。

需要的文件名（与 `web/index.html` 里的 `DONATE_CHANNELS` 对应）：

| 文件名 | 显示名称 |
|---|---|
| `wechat.png` | 微信 |
| `alipay.png` | 支付宝 |
| `coffee.png` | 请我喝杯咖啡 |

- 推荐正方形 PNG，300×300 以上，背景尽量干净。
- 不放图片也没关系：页面会显示「把图片放到这里」的占位说明，不会破图。
- 这些图片**不会被 git 追踪**（见仓库根 `.gitignore` 的 `web/donate/*.png` 规则），
  因此你的收款码不会被提交进公开仓库；若想随仓库发布，请自行移除该忽略规则。

# 阿澈桌面端 · 界面设计交付 v1.0

> 2026-11-17 · 420 × 760 基准窗口 · 5 个页面（含版式对照）· 纯 HTML/CSS/JS，无依赖

## 0. 怎么看

双击 `index.html` 打开规范总览，右上角可切换晨光 / 暖夜，页内三个按钮进入各页面。

| 文件 | 内容 |
|---|---|
| `index.html` | 设计系统总览：颜色、排版、间距、组件、无障碍、交付表 |
| `chat.html` | 对话页（示例对话已载入，五种状态都能在页面上看到） |
| `chat-options.html` | 三种对话页版式对照（实时预览），点开即设为默认 |
| `settings.html` | Agent 人设设置（分组列表 → 分组详情，宽屏自动双栏） |
| `popup.html` | 主动关心弹窗（角落浮层） |
| `assets/tokens.css` | 设计令牌：明暗双主题的颜色、字体、间距、圆角、阴影、动效 |
| `assets/ui.css` | 组件原子：印章头像、按钮、表单、药丸、芯片、菜单、Toast、弹层 |
| `assets/pages.css` | 页面组合：对话、设置、弹窗、规范页、响应式 |
| `assets/layouts.css` | 对话页三种版式：舒展 / 信件 / 极简，以及版式对照页 |
| `assets/app.js` | 交互原型：发送 / 在想… / 主动关心 / 设置路由 / 预览抽屉 / 确认弹层 / 主题 |

对话页「⋯」菜单里有两组原型开关：**版式**（舒展 / 信件 / 极简，会记住选择）和**原型演示**（空状态 / 在想… / 主动关心 / 发送失败）。演示项上线前删掉即可（同时删掉消息流里带 `data-sample` 的示例对话）；版式可以保留成真实偏好。

## 1. 需要你拍板的：弹窗 = A

**建议选 A（主动关心弹窗）**，理由是它和你现有能力严丝合缝：

1. `proactive()` 接口已经就绪，弹窗只是把它渲染成一张卡片，不需要新后端。
2. 陪伴感来自“它想起你”，而不是“你随时能叫它”。角落一张小卡刚好表达这件事，且不打断你手上的窗口。
3. 工作量最小、风险最低；做完 A 之后再加 B 不会推翻任何结构。

B（常驻悬浮球）放二期：真正的工作量不在球本身，而在置顶窗口、跨屏 DPI、位置记忆、唤起后回到对话的焦点交接。现在做会拖慢主线。

C（设置改模态层）不建议替代第 2 页：人设六组字段加宪法五项，内容量太大，420 宽的模态层最后还是会变成整页。当前设置页已经兼容宽窗双栏，想要“轻一点”只需从顶栏打开，不需要改形态。

### 弹窗规则（按 A 落地）

| 项 | 规格 |
|---|---|
| 尺寸 | 352 宽，内容自适应（约 186 高），圆角 20，1px 发丝线 + sh-3 |
| 位置 | 屏幕右下，距边 16px；对话页内演示时距底部 108px，避开输入区 |
| 出现 | 210ms 上浮 6px + 淡入，无声音；**不抢焦点**，不置顶于其他应用 |
| 关闭 | × / Esc / 先不用；同时最多存在 1 张，新的排队 |
| 回应 | 跳回对话页，把话题预填进输入框（**不自动发送**），焦点给输入框 |
| 忽略 | 淡出并记一次“已放下”，同一话题 24h 内不再提，睡前可再提一次 |
| 频率 | 由设置页「主动性 1–5」控制；默认 3（偶尔主动） |

页内演示：对话页点「主动关心」，或打开 `popup.html`。回应会带 `?topic=` 跳回对话页并预填。

## 2. 三个页面

### 2.1 对话页 `chat.html`

结构：顶栏（58px）/ 消息流（弹性滚动）/ 输入区（固定底部）。内容列最大 720，420 窗口下左右留白 18。

**五种消息状态**

| 状态 | 处理 |
|---|---|
| 空状态 | 印章嵌在 72px 纸牌里（像盖在信封上），宋体 24px 一句引导 + 三条建议；建议只预填，不替你发送 |
| 你的消息 | 右对齐，陶土纸色气泡，16/16/5/16 圆角，无衬线 14px |
| 阿澈的消息 | 左对齐，24px 印章 + 纸白气泡，**宋体 14.5px / 1.82**；下方 11px「已记住 · …」带书签小标 |
| 在想… | 印章 + 三个 4px 呼吸点 + 11.5px 文案；同时顶栏状态从「在」变「在想…」 |
| 主动关心 | 暖陶土底色气泡，顶部一行 10.5px 标签「阿澈 主动来找你」，两个按钮；回应/忽略后原地留一行淡字 |

**其他已设计状态**：发送失败（输入框上方错误条 + 重发）、空历史（同空状态）、忽略后的收束态、输入框聚焦环、发送键禁用态。

**三种版式**（同一份 DOM，切换 `<html data-layout="air|letter|quiet">`，令牌与文案不变）：

| 版式 | 做法 | 感觉 |
|---|---|---|
| 舒展（默认） | 保留气泡；消息间隔 24px、内边距 22px；印章改空心、去第二条时间线；输入区只留一行按键提示 | 最像“有人在旁边” |
| 信件 | 去掉所有气泡：阿澈的话是带 1px 细竖线的宋体正文，你的话是右侧带陶土细线的批注；输入区变成一条书写线 | 最安静，最不像聊天软件 |
| 极简 | 收起头像、逐条回执与时间戳，用一行“今晚记住了 2 件事”代替；气泡更紧凑，输入区变胶囊 | 一屏多放两条消息，适合高频使用 |

- 切换入口：对话页「⋯ → 版式」，或 `chat.html?layout=air|letter|quiet` 直达；选择写入 `localStorage`（`ache.layout`）。
- 对照页：`chat-options.html` 三栏实时预览，点“打开这一版”即设为默认。

**交互细节**

- Enter 发送，Shift + Enter 换行；判断 `isComposing`，中文输入法选词时按回车不会误发。
- 输入框随内容长高，最高 132px（约 6 行）后内部滚动。
- 发送后 1.1–1.8s 出现回复（原型模拟），回复自带「已记住」回执。
- 消息入场 420ms，逐条 60ms 级联；`prefers-reduced-motion` 下全部静止。
- 顶部「⋯」菜单：暖夜模式、陪我听歌（规划中）、帮我操作电脑（规划中）——未来模块只留入口，不做功能。

### 2.2 人设设置 `settings.html`

窄窗（< 980）走**分组列表 → 分组详情**：先看到阿澈摘要卡（印章、名字、一句话、v3、宪法 v2），再是 6 行分组，每行带图标、条目数或「高级」标记。点进一组只面对 3–6 个字段，比在 420 宽里滚一张长表轻松。

宽窗（≥ 980）自动变**左导航 + 右表单双栏**，不用改任何标记，拉伸窗口即可看到。

| 分组 | 字段 | 备注 |
|---|---|---|
| 基本 | 名字、身份一句话、性格 ×8 | 性格是芯片，回车添加，超 8 条禁用输入并提示 |
| 说话方式 | 风格、长度、怎么称呼对方、口头禅、避免 | 风格/长度用药丸单选，避免长下拉 |
| 关系与相处 | 对方称呼、关系定位、主动性、关心方式、情绪基线、绝对不做 | 主动性 1–5 滑杆，带档位文案与 `aria-valuetext` |
| 示范语气 | 2 组「对方说 / 我回」 | 只学语气，不当经历；≥720 宽时双列并排 |
| 固定身份宪法 | 我是谁、我服务谁、称呼与边界、语气与禁忌、能力边界 | 默认折叠，顶部琥珀色提示「优先级高于人设」 |
| 版本历史 | 版本号、名字、归档时间、操作人、说明、恢复 | 当前版本描边高亮；恢复走确认弹层，文案说明会生成新版本 |

**底部操作**：窄窗显示「更多 + 保存新版本」，四个次要操作收进底部动作面板；宽窗平铺为「预览注入 / 填入示例 / 清空 / 放弃修改 + 保存新版本」。
- 预览注入：右侧抽屉，等宽字体展示拼好的注入文本，可一键复制。
- 填入示例 / 清空为骨架 / 放弃修改：都走统一确认弹层（危险操作用陶土红），避免误触。
- 脏状态：顶栏从「✓ 已保存 · v3」变为「• 未保存的改动」，底部提示同步变化；保存后版本号 +1，提示「下一句话生效」。
- 恢复历史版本会落到表单里，仍需保存才生效——和接口行为一致。

### 2.3 主动关心弹窗 `popup.html`

单卡：印章 + 名字 + 时间 + 收起，宋体正文两句以内，右下两个按钮。回应 → 对话页预填；先不用 → 淡出，页面给「再看一次」，方便评审反复看。

### 字体

- 字重只用 400 / 500。标题不加粗，靠字号与留白分层。

| 宽度 | 行为 |
|---|---|
| < 380 | 隐藏输入区按键提示，左右留白 14，避免四个演示链接换行挤压 |

## 6. 无障碍（WCAG 2.1 AA）

- 所有正文/背景组合 ≥ 4.5:1，大字 ≥ 3:1（数值见上表，按 WCAG 相对亮度公式计算）。
- 语义结构：`h1` 页面标题、`nav` 分组、`section` + `h2/h3`、`role="log"` 消息流、`role="alert"` 发送错误、`role="alertdialog"` 确认层。
- 键盘：Tab 顺序为「头像 → 状态 → 菜单 → 设置 → 消息 → 输入 → 发送」；菜单支持 ↑↓ 与 Esc；抽屉/确认/动作面板有焦点循环、Esc 关闭、关闭后焦点回到触发点。
- 主动关心是**非模态**浮层，不抢焦点；回应只预填，不自动发送。
- 输入框有 `label`、`aria-describedby` 说明；发送键有 `aria-label`；滑动条同步 `aria-valuetext`。
- 动效尊重 `prefers-reduced-motion`；没有自动播放的声音或视频。
- 200% 缩放：单列布局，气泡与表单不溢出；触摸目标最小 34px 的胶囊在粗指针下升到 44。
- 颜色不是唯一信息载体：在线状态有文字「在 / 在想…」，错误有图标 + 文案，选中态有字重变化。

## 7. 接 DeskAPI 的映射

原型数据是假的，接真接口时按下表替换即可：

| UI 动作 | 调用 | 注意 |
|---|---|---|
| 启动加载历史 | `DeskAPI.history(30)` | 渲染成消息流；失败时保留空状态并给一行「历史没加载出来」 |
| 发送 | `DeskAPI.chat(text)` | 期间显示「在想…」；失败显示错误条，保留原文供重发 |
| 主动关心 | `DeskAPI.proactive()` | 有内容才浮出；同一时间最多 1 张；忽略记 24h |
| 保存人设 | `DeskAPI.personaSave(card)` | 内部已做「校验 → 保存 → reset」，**UI 不要再调 resetLive** |
| 预览注入 | `DeskAPI.personaPreview(card)` | 抽屉内容直接用它返回的文本替换 `buildInjection()` |
| 填入示例 / 清空骨架 | `DeskAPI.personaTpl("example" / "skeleton")` | 原型里是前端假数据，上线改为取后端模板 |
| 版本历史 / 回滚 | `personaHistory(limit)` / `personaRollback(v)` | 回滚后刷新列表并提示「保存后生效」 |
| 宪法 | `identitySave(profile)` | 单独保存，UI 已标明优先级高于人设 |
| 系统通知 | `DeskAPI.notify(title, msg)` | 可选：浮层出现时同时发一条系统通知 |

保存后的「下一句话生效」文案对应 `reset` 的行为，UI 不需要重启对话窗口。

## 9. 相对初版想法的改动

| 改动 | 原因 |

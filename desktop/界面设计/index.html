晨光纸页

陪伴型 agent 的界面应该像一张摊开的纸，而不是一块发光的玻璃。暖纸底、发丝线、陶土色的一点点重量； 阿澈说的话用宋体，界面用无衬线——两种声音，一眼分得开。白天是纸，夜里是一盏没关的灯。

设计立场 01

这一版最容易被认成“网页”的地方，是上一版用了深色底 + 发光强调。这一版反过来：底色是纸，强调色只有陶土一种， 深度靠 1px 发丝线和 4px 级的留白节奏，而不是投影堆叠。整个界面只有三处允许出现阴影——浮层、输入框、对话气泡。

  • 纸，不是玻璃。没有毛玻璃、没有霓虹渐变、没有纯黑纯白；背景颗粒是固定的 5% 噪点层，不参与滚动重绘。
  • 衬线是它的声音。阿澈的每句话用 Noto Serif SC 排版，行高 1.82；你的话是 13px 无衬线气泡。抬眼就能分清谁在说。
  • 主动必须留退路。主动关心永远带“先不用”，浮层不抢焦点、不遮输入区；回应只预填话题，不替你发送。
  • 高级项要收起来。身份宪法和版本历史放在“高级”里折叠，默认不打扰日常设置。

对话组件 05

五种状态共用一套骨架：印章头像 24px、气泡 16px 圆角、说话方一侧收角 5px。记忆回执永远比正文淡一级，不抢注意力。

对话页有三种疏密——舒展 / 信件 / 极简。同一份 DOM，切换 data-layout 即可，令牌与文案不变。

无障碍 06

按 WCAG 2.1 AA 落地：正文 4.5:1 是底线，大字 3:1；焦点永远可见；键盘能走完所有流程；动效可以关掉。

  • 正文墨色对纸底 12.7:1；次要文字 6.9:1；三级文字 4.6:1；主按钮白字对陶土 5.7:1。
  • 暖夜主题：正文 14.3:1、三级文字 5.7:1、陶土强调文字 6.0:1。
  • Tab 顺序：顶栏头像 → 状态 → 菜单 → 设置 → 消息流 → 输入框 → 发送；抽屉与确认弹层做了焦点循环与 Esc 关闭。
  • 输入框有真实 label、说明与 aria-describedby；回车发送会避开中文输入法组合态。
  • 主动关心是非模态浮层：不抢焦点；回应只预填，不自动发送。
  • 交互元素粗指针下自动升到 44px；prefers-reduced-motion 下所有循环动效静止。
  • 浏览器缩放到 200%：420 宽窗口回落为单列，气泡与表单不溢出。
